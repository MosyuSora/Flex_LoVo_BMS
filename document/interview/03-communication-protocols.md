# 通信协议设计与踩坑

> 状态：提纲已建立，内容待补充。

## 专题目标

梳理 CAN、UART、Bootloader OTA 和上位机之间的协议边界，解释报文设计、
容错机制和联调问题。

## 问题池

- CAN 报文 ID、数据字段、字节序、缩放和刷新周期如何设计？
- 周期报文与事件报文如何取舍，带宽和优先级如何评估？
- UART 调试协议如何兼顾可读性、稳定性和自动化解析？
- CAN OTA 如何处理分包、顺序、超时、CRC、断电和恢复？
- 多端联调时，如何定位协议定义、实现和工具之间的不一致？

## 项目证据

- 待关联 CAN 协议定义、UART 日志、Bootloader OTA 工具和 Python 上位机解析。
